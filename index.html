Sobre o Sistema de Biblioteca

Este sistema foi desenvolvido como uma solução completa para controle de acervo bibliotecário e fluxo de empréstimos, originalmente implementado com backend em Python e banco de dados relacional PostgreSQL 18.

⚡ Regras de Negócio e Triggers

  • Trigger trg_valida_emprestimo: Bloqueia novos empréstimos caso todas as cópias físicas do livro já estejam emprestadas.
  • Trigger trg_valida_exclusao_aluno: Permite a exclusão de aluno apenas se todos os seus empréstimos constarem como devolvidos.
  • Autenticação Segura: Criptografia de senhas com Salt aleatório e hash SHA-256.
